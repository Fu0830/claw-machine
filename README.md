# 可爱抓娃娃机

一个柔和可爱画风的抓娃娃机 H5 小游戏，纯静态页面，无需构建、无需后端，打开 `index.html` 即可游玩。

## 玩法

- 左右移动机械爪，对准喜欢的玩偶后按下「下爪」。
- 爪子下降、合拢，靠近玩偶即可抓住；抓到的玩偶会被送到右侧收藏洞陈列。
- 共 5 次机会，结束后按抓到数量给出评价，可随时再玩一次。
- 操作：键盘 ← → 移动、空格下爪；手机点按屏幕两侧按钮。

## 技术说明

- 单文件 `index.html`，HTML + CSS + 原生 JavaScript，无外部依赖。
- 游戏画面由原生 Canvas 2D 绘制；爪子采用状态机（移动 / 下降 / 合拢 / 上升 / 移到出口 / 松爪 / 回位）。
- 音效由 Web Audio 合成，首次点击后才启动音频。
